1. `git pull` (hoặc fetch + reset --hard origin/main), chạy `scripts\DEPLOY-AMS-ANIO-VN.bat`. Migration 0006–0015 tự áp.
2. Đặt AMS_SECRET_FIELD_ENC_KEY cho gateway Worker, giống api Worker (xem deploy script).
3. Thêm CORS trên R2 bucket media cho https://ams.anio.vn (PUT).
